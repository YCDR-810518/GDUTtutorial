## 基本信息
> 从哪开始讲起呢……算了想到啥说啥吧()

### 分班
- 除了特定班型高考直接选入，其他大部分都是随机分班。分班结果一般在专业的QQ群会有老师发。
- 会有【助班师兄/师姐】给你收到录取信息的那个手机号打电话联系，加微信好友然后把你们拉进班群。                               ——助班类似学长团
- 大学的班群一般分为两个，禁水群和水群。如名，禁水群有班主任在（班主任也是后面才进群），主要是以后班委发布通知或者签到二维码用，严禁随意聊天；水群可以随便聊（如果你足够社牛）。
- 开学之后师兄师姐可能还会给你们整个破冰，做好心理准备。

### 早晚自习
- 广工的大一上学期是有早晚自习的（对！是的！你没听错！）
- 早自习是周一至周四的7.45-8.15，晚自习是周一至周四的19.20-20.55，中间没有下课，休息时间自己决定。开展时间为第2周至第17周。
- 其实个人感觉没啥用……尤其早自习，赶过去赶回来二十分钟在那里自习半个小时不知道何意味……不过一般大一上辅导员都会查的，严格程度依专业以及辅导员而定。
- 一般是每个班的纪律委员设置签到码早晚定位打卡并上报辅导员，可以和纪律委员打好关系。
- 建议前期不要逃哈！逃了被抓了自己负责哈！
- 对了补充 一般是连号的三个班一间教室（比如123在一号教室 456二号），并且我们这一年有的专业连座位都分好了，实行萝卜坑制，谁没去一目了然。

### 军训
- 军训时间学校都会统一通知的，这个不固定，为看到这篇文章的新生祈祷阳光中……（一张植物大战僵尸里的向日葵.jpg）
- 军训服一般会让提前买，学校也会统一通知。在开学的那几天有固定的地点卖军训服。是的！大学的军训服也得自己买！（到底是什么样的人才能设计出这种既不美观又不实用还腰宽裆高的衣服……）
- 建议买两套+一双鞋子换着穿，要买一套其实也无所谓，碰到下雨天衣服干不了可能有点难办。
- 建议自带腰带，那个腰带有点劣质。
- 军训服军训完之后不要丢！！不要丢！！不要丢！！你们后面还有一门课叫工程训练会用到，每个专业都必须上的。（预告一下就是类似进厂打螺丝）

### 宿舍
- 宿舍可能是五人间可能四人间，截至本文完稿前仍未清楚宿舍究竟如何安排，顺其自然。
- 电器类：建议携带电吹风、烧水壶、手机、电脑、小风扇、充电宝，其余看个人：平板、宿舍集资小冰箱乃至厨具等。（如果你觉得空间足够的话……以及要和舍友商量）

- 宿舍是要集资购买洗衣机的，不像高中都配置好了。在分好宿舍之后（大概在开学前几天）积极一点组建宿舍群，和舍友商量好买什么洗衣机以及要不要买饮水机冰箱什么的。
- 饮水机可以不用购买，有个小程序【真如校园】订购桶装水，一月两桶男生宿舍都够了，自己上网买一个按压水泵就可以了。
- 建议提前选好宿舍长（也可以等师兄师姐来问的时候再选），顺便制定好宿舍公约，比如打扫卫生以及几点熄灯什么的，以后会方便很多，有生活习惯不同的舍友想要换宿舍的时候也可以拿着宿舍公约去找辅导员。
- 关于床上用具，建议购买那种整套的带床帘和蚊帐的框架，有财力（划掉）能力的可以买里面能挂风扇的、有口袋的。床的具体尺寸这边我查不到了，可以到时候在专业群里问，差不多和科高的一样大。
- 阳台比科高小多了，厕所和淋浴是连在一起的，阳台放了个洗衣机之后基本上最多只能同时站三个人，做好心理准备。

### 开学第一周
- 确定班级宿舍之后到看宿舍的那个页面，能发现一个叫【迎新使者】的栏，里面有联系方式，一定一定一定要添加Ta！开学那几天Ta会和你联系，负责接你和你的家长到宿舍，帮你办理证明，发给你学生卡。
- 第一周基本上都是一些讲座，有的重要有的不重要，自己分辨，像是师兄师姐传递经验就可以认真听记笔记。
- 第一周建议没事多逛逛学校熟悉一下。

### 设施介绍
> 结合最上方地图理解。
- 教1-2：距离最远，主要是小教室居多，上两个班一起上的课或者单独一个班上的课，比如英语课。
- 教3-6：大一上去的最多的教室，基本为大教室，四个班一起上，比如高数、线代、水课等，其中教6基本没去过，教5考试去居多，教3、4最多。
- 工学馆+实验楼：工学馆一般上到需要用电脑的课才去，一些工作室实验室的工位也在这里。以及辅导员、院长、部分老师的办公室。对了开学第一周有的课是在这里上的，有一个类似大教室的阶梯教室。实验楼是上金工实习的时候才会去
- 
- X号大教室：1号2号……这些，所有大教室均匀分布在教一教二与教三教四中间，第一周大部分课也在这里上，然后就只有年级开大会或者极少数情况才会用到这里了，建议配合高德/百度/腾讯地图的地标寻找。
- 创新创业学院：教三教五的一楼，也叫创谷，里面有部分工作室的工位，剩余我也很少去，不怎么了解，可以自己去了解，但是用的挺少的。
- 图书馆：自习圣地，一楼进不去，走那个大楼梯直接上二楼进。有安检，后期有录入人脸可以直接人脸识别进入，刚开学（多久忘了可能是半个学期？）没有人脸，只能携带自己的学生卡（蓝蓝的有你高考时候拍的丑照的那张）刷卡进入，或者在企业号广东工业大学->工大校园卡有电子卡。每周五下午有消毒时间，不许进入，其他时候都是早上七八点开门，晚上10.15关门，没买车建议提前走因为很晚就没有共享单车了。早上去的很早没空调。
- 文化活动中心：看表演的地方，团委办公也在这。
- 体育场：分为国防生体育场（小，图书馆后面）和正常那个（大，不知道咋称呼 在西区对面）
- 足球场在国防生体育场那里，篮球场都有，羽毛球场在大体育馆的“地下”，在里面多逛逛发现通向下方的楼梯就是，要线上预定。健身房也在大体育场，不是有足球场和跑道旁边那个，在游泳池和器材室附近。


### 社团/学生组织
- 一般来说开学第一周或是前半学期会有招新宣传，没事的时候别宅宿舍多去文化活动中心前面或者创谷逛逛，看到有感兴趣的直接上去咨询。
- 不像高中会有到每个班的宣传，这个纯靠自己，有消息渠道也是你和别人拉开差距的一部分。
- 会干活，组织活动，会给时长。时长有四种类型，后续再了解。平时不加入学生组织参加活动也可以获得时长，但是进社团/组织会更简单。
- 分校级、院级，更高级的组织/社团对你的帮助会更大，但也更难。
- 主要还是一个认识朋友、认识师兄师姐的渠道。


### 工作室/实验室
> 一个广泛认知是：读研进实验室，就业进工作室。但是万事不绝对，看自己选择。
- 实验室和很多人理解中的一样，就是“进组”，指导老师研究课题的时候会招，头上有指导老师、师兄师姐，跟着能获取很多消息，也可以为自己日后考研保研做准备。
- 工作室是我们学校的一个特色，偏向就业，进了工作室能学到更多和就业接轨的知识，加上泥工（你广工）在这一带广泛的认可和影响力，使本科就业且工资不俗成为可能。
- 实验室和工作室都可以在大一上好好了解，都是大一下开始招新。认识的最厉害的大一下开学没多久就已经开始进课题组跟着老师看论文了。
- 如果对工作室有意向推荐了解QG工作室奥。（夹带私货）


### 校服/校园网/校园卡
- 校服穿的很少，可以不买，只有个别志愿者活动和会议会用到，比如校运会，学生代表大会，一些团组织的活动，学校级的志愿者活动等。如果你比较喜欢参加一些活动，或者加入了一些学生社团或部门，可以买，一般会用得上，不买的话就找别人借也可以
- 校园网的话，看个人需求，校园网的优势就是可以在学校几乎任何地方都可以连（有些网站也一定要校园网打开比如体测成绩查询的网站，以及知网等一些网站用校园网也是可以免费浏览），很方便，也不用考虑流量消耗（但校园网只能连接2台移动设备和一台网线直连），如果不买校园网流量也够用的话，可以用手机给电脑开热点（当然这么做就是有点不方便，也需要考虑流量消耗），我也有同学是宿舍里三个人一起买校园网（平均一个人一个月10块但是只能在宿舍里面连），也买了个路由器，然后接了网线（他是在校内买的路由器，和网线一起是200，应该网上买的路由也是可以的，但是没试过），整个宿舍连一个路由WIFI（他们宿舍三个人一起连不卡）
    * 我是使用宿舍路由器的学长，宿舍路由器亲测非常好用，**不要在校内买路由器，直接上网买**，直接在淘宝/拼多多买一台路由器就能用，具体如何安装和使用路由器见[宿舍的无线网络网络改良方法](宿舍的无线网络改良方法.md),上面他说的不太对，其实校园网可以连接**三台**无线设备和**一台**有线设备
- 校园网在人用的比较多的时候，有时候也会有点卡，具体用不用看自己（校园网30块1个月买五个月送一个月）
- 我个人是办了张副卡专门用于提供流量，一个月200+G足够了，手机开热点给电脑连，偶尔几次用到校园网就找舍友礼貌借一下用完就关掉。如果要自己办流量卡的可以B站搜【流量卡大忽悠】。我的是29r/月，不过这个套餐应该是已经没有了。
- 校园卡 ≈ 流量卡，只不过会有很多师兄师姐来给你推因为他们有提成。这个见仁见智吧，最开始都会用价钱便宜来诱惑你，但是后面出了问题比如网卡或者什么的他们可以不负责的。身边也有同学买，但这个我就不太了解了，只是他给我的感觉不是很好不太建议，仅为个人观点。

### 校园跑
> 为什么要校园跑，改成校园睡不好吗。
- 校园跑也算是大学生不得不体验的一环了。
- 我们学校是每学期72km，每天、每次最多跑两公里，最少跑两公里，意味着一个学期你要跑36天。（比如你一次性跑了三公里，但是不好意思只能计两公里；一次性跑了1.9公里，不好意思没达标不算成绩）
- 需要通过一个叫运动世界的软件登记，拿着手机跑（图标是黑色背景加绿色的S，可以先下载）
- 不过这个软件也叫广告世界，极其容易跳转到广告页面。
- 开学不用急着跑，你们要军训后才能开始跑。
- 简化校园跑的方法你们日后在生活中会自己学到的。

### 通勤
> 考虑到男女生、堵车、没车以及其他因素，以下时间范围波动较大。注意从宿舍到大门的时间。
- 到教1-2以及工学馆，从西区东门（西区上课都走这个门）出发，大概需要8-15分钟。
- 到教3-4，一般需要6-8分钟，（个人最高纪录4分钟）
- 以上都是骑自行车的时间，我们学校有很多共享单车，可以上美团学生认证然后办一个9.9的月卡，一个月免费骑。
- 也可以自己买自行车，南亭有，自行寻找，不过要砍价。建议先骑一周共享看看再决定买不买，也可以找师兄师姐买二手。

### 南亭
- 是学校旁边的一个村子，但是有很多餐馆，也有其他如理发店台球KTV健身房等，可以简单理解成大学生生活中心。学校食堂吃腻了基本上都去那里。
- 理发店没有推荐。有时候剪得还行有时候很丑。
- 建议自行探索，有很多，小巷子里的可能还会发现宝藏。以下是我自己觉得好吃的，地点自行探索（排名不分先后）：重庆鸡公煲、盖码饭、藤椒鸡、深井冰粉、兰州启虎拉面、河南面馆、一粉鲜、四川小吃、好口福、东北菜馆、馕来了……


### 五饭六饭
> 众所不周知我们学校主要有四个学生食堂，东区西区分别两个，东区靠近医院和健身房的为一饭，靠近教学区的为二饭，西区靠近教学区的为三饭，远离教学区的为四饭。五饭六饭则是每天晚上刷新在三饭门口那条路上的流动小摊。
- 刷新时间不定，大概在晚上十点左右，我们大一上学期是晚上十一点半刷新，下学期是晚上十点刷新。
- 应有尽有，烤串炸鸡炒面啤酒水果捞，家里不让吃的可以敞开吃，不过自己要注意饮食安全。
- 个人推荐为：一个夫妻档的关东煮、黄金甲土豆、鲜肉饼、橄榄菜炒饭、章鱼小丸子、煎饼果子、彩虹牛肉、忘川椰奶清补凉，其他自行探索。

### 其他
- 大一上体育课不能选，都是篮球，但是可以选老师，到时候自己和群里的师兄师姐打探。
- 也不能选选修课，只有一个大学生健康教育可以选自己上不上（选修课就是你自己安排每个学期上几节，毕业前要修满学分）
- 必修课不能选老师，都是分配好的。
- 小程序【场馆预订】，可以预订羽毛球场等，必须要校园网才能登进去。
- 健身房也要线上预定。
- 一些软件基本所有专业都会用到，可以在家就先下好：运动世界、Welearn、U校园、U校园AI版、学习通、知到、易班、钉钉。（有几个不一定用到，先下了再删也不迟）
- 大学易班只有期末考试，有的课程可能会有期中考试，但总之一门课一学期最多不会超过四次考试。也没有考试卷子，老师负责任就会划重点给模拟卷，不然可能只会告诉你整本书都是重点让你看书。可以在网上找历年真题或者找师兄们。
- 建议开学前学会单手骑自行车，不会的话下雨天很难办的。

## 杂言碎语

- 大学一般称呼师兄师姐比较多，我好不容易才从学长学姐改过来……
- 放开一点多和师兄师姐打好关系尤其是同专业的！！真的有很大帮助，能帮你打破信息壁垒，也可以带你打比赛混奖励，我当时就是放不开……
- 不用太早为了考研保研还是就业焦虑，都需要绩点，且绩点是很重要的一环。可以先好好学习让自己绩点考好一点（不太理解的话就是期末考试均分90+），我们甚至有师兄大二下学期才想好要走什么方向但也获得成功的。
- 刚开学一两周很多混进学校的自称师兄师姐（也可能真的是师兄师姐）让你们加入什么英语角（这个骗人概率挺大）、驾校群、家教群等等诸如此类，结合自己情况决定要不要加，觉得烦人直接删了也没事。这些就是看新生刚进学校又天真又不会拒绝才会使劲在你们宿舍宣传的，一定要明确拒绝之后他们才会走得快！不然叨叨半个小时起步。
- 学校里偶尔会出现那种卖惨的或者拉着你宣传啊让你支持大学生创业啊什么的，最经典的就是卖笔，两支笔四十，这种就不要和他纠缠，有多远走多远。
- 很多东西都建议先找师兄师姐买二手，比如课本、自行车或者其他。
- 大一上新奇感过完之后很普遍的一点就是迷茫。大学不像高中有明确的任务——学习。在大学，自己选择道路才是常态。以计算机类为例，你要思考自己未来选择计科或是软工或是其他，还要思考选完专业之后以后就业是搞前端/后端/嵌入式/AI/移动/图形等，加上大学的课很多可能一两节体现不出意义，作业以周为单位布置且一般比较少，你会不知道自己要干嘛。每天就是上课刷手机，回宿舍打游戏，很容易陷入“累，但不知道为什么累的情况”，甚至想回高三休息几天。这时候我的建议是抽出课少的几天或是周末，认真思考自己的未来，用笔写下来，比如我以后向赚大钱，可以通过提高学历/提高能力两种方式，提高学历就要保研/考研，多去网上搜索看看哪个更适合你；提高能力可以选择加入工作室或自学……这样从最终目标一点点往下思考，一直到最后给自己定一个最简单的近期目标如“打一个有含金量的比赛”、“期末绩点考到年级前10”。而不是脑子里只有“我要考好”，然后不知道下一步的规划。
- 大学自学是很重要的学习方式，甚至有时候比上课还重要。多使用B站大学、github这样的渠道获取知识。
- 关于谈恋爱，说真的其实“大学一个学期和异性的交流不如你高中和同桌一节晚自习的交流”，一般来说挺难接触到异性的，能谈到算你有本事。不过擦亮眼睛别被骗就行，大一刚开学都想谈恋爱，但是没考虑好可能会牵制你很大部分精力。
